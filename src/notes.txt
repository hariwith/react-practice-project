useEffect(callback,dependencies)

useEffect(()=>{
    #logic
},[])

it is known as sideEffect,used to control the components by rerendering whenever there is a change in state 
it contains two parameters 
1.Callback -  where the logic is executed
2.dependencies - 

whenever there is empty dependency(empty array) the program will execute only once if there is no dependency the program will execute again and again whenever there is change in state
